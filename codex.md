## Dataset Indexes

`dataset_manifest.json` summarizes dataset generation: requested samples,
success/failure counts, runtime, and aggregate temperature statistics.

`dataset_index.csv` and `dataset_index.jsonl` are generated by
`scripts/build_dataset_index.py` and are intended for ML loading and filtering.
The CSV is a flat table for quick inspection; the JSONL preserves richer fields
such as benchmark metadata, per-type power summaries, and block temperatures.

A future `ChipThermDataset` loader should read from one of these index files
rather than walking sample directories directly.
